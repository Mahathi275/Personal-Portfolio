# Personal Portfolio Website

A clean, modern, and fully responsive single-page personal portfolio website built using **HTML5**, **CSS3**, and **Bootstrap 5**. Designed to highlight academic background milestones, skill fields, and developmental project targets.

This setup fulfills the project criteria for **Project 1** under the Glow Logics training program.

## 🛠️ Tech Stack Used

- **HTML5** & **CSS3**
- **Bootstrap 5 (via CDN)**
- **Netlify Platform Hosting**

## 📂 Structural Layout

```text
├── index.html         # Main structure
├── style.css          # Custom overrides
├── screenshots/       # Verification outputs
└── README.md          # Documentation
```
